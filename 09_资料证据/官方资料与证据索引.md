# 官方资料与证据索引

> 本文件只负责来源、证据等级、研究边界和原始资料定位，不作为第二个导演规则入口。研究结论必须写回对应唯一主档。

# 1. 证据等级

- **E1 官方文档直接证据**：模型官方技术文档、产品手册、大学正式课程、行业组织一手资料。
- **E2 官方案例 / 创作者一手访谈**：导演、摄影、剪辑、表演者本人或权威行业机构发布的案例与访谈。
- **E3 专业研究 / 学术证据**：同行评议论文、大学研究、经典专业理论及可信技术报告。
- **E4 项目真实实测**：本项目 Seedance / Seedream / 图像 / 视频 / 剪辑的真实生成结果与用户确认。
- **E5 待验证假设**：模型推断、单次成功、类比迁移、尚无真实复验的候选。

裁决原则：外部资料产生候选规则，不因为“有论文 / 有大师案例”就自动升级为项目稳定规则。用户真实成片反馈与重复实测决定是否晋升。

# 3. 角色自主生命连续性 CALC 的研究证据

CALC / CLCS 是本项目自定义工作名，不冒充行业固定术语。其基础来自多条成熟知识线：

## 表演与角色行动

- Stanislavski：given circumstances、行动与角色的 physical life。E3。
- Meisner / Neighborhood Playhouse / NYU Tisch 相关正式课程：`acting is doing`、independent activity、moment-to-moment truthful response。E1/E3。

项目转译：人物不是先等待情节提示再“表演情绪”，而是在既定情境中原本就在执行目标，外部刺激只改变其注意与行动。

## 导演与场面调度

- Directors Guild of America 导演访谈与专业资料：演员 blocking、行为与摄影机设计相互适配，而非先固定漂亮机位再强迫人物配合。E2。

项目转译：优先让角色目标与空间行为成立，再决定摄影机如何发现和组织它。

## 可信角色与计算叙事

- Carnegie Mellon Oz Project / believable agents：人格应贯穿语言、动作、反应；角色拥有自身目标而非只响应主角。E3。
- BDI narrative-agent 研究：belief / desire / intention 区分角色相信什么、想要什么、决定做什么。E3。
- Generative Agents：记忆、反思、计划支持持续行为与社会互动。E3，作为架构启发，不等于要求电影角色运行完整 Agent 仿真。

## 有限理性

- Herbert Simon bounded rationality：行动者受有限信息、认知和时间制约，并非全局最优求解器。E3。

项目转译：角色知识边界、误解、习惯、情绪、关系、职责可以让角色做出非最优但人物真实的选择；不得为了“人性化”故意制造无因果愚蠢。

# 4. 叙事与认知研究

项目已有长期使用的研究方向：

- 观众认知时差 / 延迟揭示
- 反应—视线—目标分离
- 声画信息分工
- 动作与说明信息并行
- 注意预算 / 揭示预算
- 场面调度与权力空间

上述方法只有在明确服务当前场景问题时调用，禁止因为是专业技巧而永久激活。

# 5. 外部资料摄取流程

```text
发现资料
→ 判断一手/二手与证据等级
→ 提取关键主张
→ 标记适用范围和限制
→ 与现有规则查重/查冲突
→ 转成可执行候选
→ 场景测试
→ 用户反馈 / 真实生成验证
→ 成熟度晋升或淘汰
```

# 6. 来源保存制度

- 原始官方资料、论文、PDF、网页快照可以放 ChatGPT Library 或外部公开链接。
- GitHub 本文件保存来源定位、证据等级、结论边界和最后核验状态。
- 受版权保护资料不复制大段全文，只保存必要元数据、短摘要和项目自有结论。
- 易变化的模型能力、产品说明和平台规则在真正使用前重新核验。
