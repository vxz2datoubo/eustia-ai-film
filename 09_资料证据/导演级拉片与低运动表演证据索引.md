# 导演级拉片与低运动表演证据索引

> 本文件保存“优秀案例必须做导演级拉片”“静止中的戏不能被当成无信息”“声音/剪辑/时长必须按功能解释”等规则的外部证据与边界。执行规范见 `10_运行时/golden_case_director_pull_schema.yaml`。本文件不建立第二份导演规则。

# 1. DGA：静默 take 用于获取纯反应表演

- 来源：Directors Guild of America，Director Nicol Paone discusses *The Kill Room*，2023。
- 等级：E2，导演一手经验 / DGA 专业机构。
- 核心主张：Paone 提到会拍“silent takes”，让演员完整跑场但不说台词，以获得更纯粹的 reactions；她明确强调自己总是需要反应镜头素材。
- 项目转译：优秀案例拉片不能只追踪“谁说了什么”；无台词段、反应、等待、视线和表面静止都可能是核心表演信息。对于无台词的情绪段，应优先检查 reaction beat、hold、micro-expression 和 internal action hypothesis。
- 边界：这是创作经验，不是统计学定律；是否需要 silent take 或长 hold 仍依赖具体剧情和演员表演。
- 核验地址：https://www.dga.org/events/2023/november2023/the-kill-room_qna_1023

# 2. DGA：静默与强声对比可产生强烈情绪/冲击

- 来源：Directors Guild of America Quarterly，`Don't Look in the Theater`，2004。
- 等级：E2，专业导演/电影工艺来源。
- 核心主张：文章记录导演 Lucky McKee 把 silence 与突然强烈、刺耳的声音或音乐进行并置，作为制造观众情绪冲击的工具，并以 Hitchcock 的对比式节奏为例说明“前后反差”比单个高响度事件本身更重要。
- 项目转译：拉片中不能只记录“门声很响”；要分析门响之前的声场密度、静默时长、动态范围变化、声音发生的确切时机，以及它是否承担 release、decision、cut-off、shock 或 scene punctuation。
- 边界：不同类型片对大动态范围的需求不同；强响并不天然等于更高级。
- 核验地址：https://www.dga.org/craft/dgaq/issues/0401-january-2004/dont-look-in-the-theater

# 3. Academy：声音是叙事与沉浸的核心组成，不是附属层

- 来源：Academy of Motion Picture Arts and Sciences，`40 Years of Sound for Film`。
- 等级：E1/E2，学院官方专业活动。
- 核心主张：学院把声音描述为建立电影可信世界、把观众带入故事的重要组成，并展示 production tracks 如何经 sound editing / design / mixing 转化为成片叙事声音。
- 项目转译：Golden Case 的声音分析必须和视觉时间轴共轴，覆盖 dialogue、silence、ambience、foley、SFX、BGM、动态范围和声画关系；声音不应退化成“有/无音乐”的标签。
- 核验地址：https://www.oscars.org/events/40-years-sound-film

# 4. DGA：声音可以在极短时间内承担多层叙事切换

- 来源：DGA，Director John Patton Ford discusses *How to Make a Killing*，2026。
- 等级：E2，导演一手访谈。
- 核心主张：Ford 说明自己会把声音作为 scene transition 和叙事组织核心，在几秒内控制 diegetic music、voice-over、对白及声音转换，以避免高密度叙事变成不可听的混乱。
- 项目转译：拉片需要问“这个声音为什么在这里进/退、和镜头或表演的关系是什么”，而不是把声音分析独立于剪辑和剧情功能。
- 核验地址：https://www.dga.org/events/2026/april2026/how2makeakilling_qna_0226

# 5. Walter Murch：剪辑优先级首先服务 Emotion / Story / Rhythm

- 来源：Walter Murch 的公开编辑方法（`In the Blink of an Eye` / Rule of Six），并参考其公开访谈与专业资料；辅助可核验来源包括 Web of Stories 与其公开访谈归纳。
- 等级：E2/E3，顶级电影剪辑师/声音设计师方法论。
- 核心主张：剪辑判断优先考虑观众情绪、故事推进和节奏，再考虑视线与空间连续性；“何时切”不是纯技术连续性问题。
- 项目转译：导演级拉片必须回答 why cut now / why hold now，而不能只列 shot length 和转场名称。对于“静止中的戏”，长 hold 如果维持观众情绪和人物内在过程，就不能因为运动量低而自动缩短。
- 边界：这是专业方法层级的启发式，不是唯一剪辑公式；项目执行仍服从当前剧情目的与用户导演判断。
- 参考：https://www.webofstories.com/play/walter.murch/293

# 6. VITED：均匀抽帧会漏掉非均匀分布的关键时间证据

- 来源：Lu et al., `VITED: Video Temporal Evidence Distillation`, CVPR 2025。
- 等级：E3，顶会同行评议。
- 核心主张：固定均匀抽取有限帧可能遗漏分散、非均匀出现的关键证据；VITED 显式寻找 temporal evidence windows 和 chain-of-evidence。
- 项目转译：0.5 秒采样只作为漏检安全网。真正持久化应由 shot boundary、动作阶段、微表情首次变化、hold/latency、物理接触、状态变化、声音 onset、用户关注点等驱动。
- 特别边界：感知去重不能把“长时间没有明显变化”全部删掉；如果持续时长本身证明人物在强撑、犹豫、等待或麻木，则需要保存 duration evidence。
- 核验地址：https://openaccess.thecvf.com/content/CVPR2025/html/Lu_VITED_Video_Temporal_Evidence_Distillation_CVPR_2025_paper.html

# 7. Google Neptune：长视频理解依赖 dense、time-aligned、多模态描述

- 来源：Google Research / Google DeepMind，Neptune，2024。
- 等级：E2/E3，官方研究 + 公开论文/数据集。
- 核心主张：Neptune 通过大模型生成 dense、time-aligned video captions，并强调长视频需要跨模态、长时间范围的推理；其评测显示 temporal ordering 和 state changes 仍是难点。
- 项目转译：拉片文件必须保留 start_s/end_s、状态变化顺序和音画共同证据，不能把整条视频压成一句总体 summary。
- 核验地址：https://research.google/blog/neptune-the-long-orbit-to-benchmarking-long-video-understanding/

# 8. Google Vid2Seq：事件描述和时间定位应该共同建模

- 来源：Google Research，Vid2Seq，CVPR 2023。
- 等级：E2/E3。
- 核心主张：dense video captioning 同时建模 temporal localization 与 event description，并将视觉与带 timestamp 的 transcribed speech 结合。
- 项目转译：Golden Case 的导演拉片与 timeline 应支持“几秒发生什么”以及“这个表演 beat 在几秒发生”的双向理解；声音、台词和画面共享同一秒级坐标。
- 核验地址：https://research.google/blog/vid2seq-a-pretrained-visual-language-model-for-describing-multi-event-videos/

# 9. Meta PLM-Video：时间→描述、描述→时间和主体连续轨迹

- 来源：Meta AI Research，PLM Data / PLM-Video-Human。
- 等级：E1/E3，官方研究数据发布。
- 核心主张：包含 Region-based Video Captioning、Region-based Dense Video Captioning、Region-based Temporal Localization 等训练任务，支持细粒度视频理解和时空 grounding。
- 项目转译：Director Pull 必须允许 `time → description`、`description → time`，以及同一人物的连续 beat trajectory；这为“她什么时候开始红眼”“强撑持续了多久”提供标准数据结构。
- 核验地址：https://ai.meta.com/datasets/plm-data/

# 10. Qwen2.5-VL：现实秒数是视频语义的一部分

- 来源：Qwen 官方，Qwen2.5-VL。
- 等级：E1，官方技术资料。
- 核心主张：dynamic FPS training + absolute time encoding，把时间位置与真实时间流速直接对齐，支持 second-level event localization。
- 项目转译：项目的人类可见主时间坐标必须是秒，而不是 frame index；frame index 仅作技术辅助。
- 核验地址：https://qwenlm.github.io/blog/qwen2.5-vl/

# 11. ByteDance Seedance 1.5 Pro：声音、动作、语气和叙事应联合评价

- 来源：ByteDance Seed，Seedance 1.5 Pro 官方发布与技术报告，2025。
- 等级：E1。
- 核心主张：原生 audio-visual joint generation，强调 lip-sync、intonation、performance rhythm、motion、visual impact 和 narrative coherence；后训练采用高质量数据 SFT 与多维 reward RLHF。
- 项目转译：优秀案例拉片必须把说话方式、语气、节奏、BGM、SFX、环境声和表演一起看，而不是“先看画面、声音只转字幕”。
- 核验地址：
  - https://seed.bytedance.com/en/blog/sound-and-vision-all-in-one-take-the-official-release-of-seedance-1-5-pro
  - https://seed.bytedance.com/zh/public_papers/seedance-1-5-pro-a-native-audio-visual-joint-generation-foundation-model

# 12. Seedance 2.0：复杂运动与物理提升来自多因素，不应只归因于 caption

- 来源：ByteDance Seed，Seedance 2.0 Official Launch，2026-02-12。
- 等级：E1。
- 核心主张：统一多模态音视频联合生成架构，提升 complex interaction、motion stability、physical accuracy、visual realism 与 controllability。
- 项目转译：拉片抽出的“动作自然”“物理真实”只能形成案例机制与 Prompt 假设；不能因为成片好就单独把效果归因给一句 caption 或某一个 prompt token。
- 核验地址：https://seed.bytedance.com/blog/seedance-2-0-official-launch

# 13. Prompt-A-Video / VPO：Prompt 优化必须看最终视频反馈

- 来源：Ji et al., `Prompt-A-Video`, ICCV 2025；Cheng et al., `VPO`, ICCV 2025。
- 等级：E3，顶会同行评议。
- 核心主张：Prompt-A-Video 用 reward-guided prompt evolution、SFT 和 DPO 让 Prompt 适配具体视频生成模型；VPO 把 text-level 与 video-level feedback 一起用于 prompt preference learning。
- 项目转译：导演拉片不是终点。真正学习闭环是案例分析 → 机制蒸馏 → 当前任务 Prompt → 真实生成 → 用户/结构化视频反馈 → Final-Delta → 更新案例边界。
- 核验地址：
  - https://openaccess.thecvf.com/content/ICCV2025/html/Ji_Prompt-A-Video_Prompt_Your_Video_Diffusion_Model_via_Preference-Aligned_LLM_ICCV_2025_paper.html
  - https://openaccess.thecvf.com/content/ICCV2025/html/Cheng_VPO_Aligning_Text-to-Video_Generation_Models_with_Prompt_Optimization_ICCV_2025_paper.html

# 14. 项目综合结论

当前可高置信采用：

1. 每个显式 Golden Case 都做导演级拉片，不只是存 Prompt/帧/标签。
2. 有成片时拉片必须基于秒级声画证据；只有 Prompt 时只能做前瞻分析，不冒充已观察成片。
3. “静止中的戏”是独立高价值类别：低运动不等于低信息，持续时间可以成为一级证据。
4. 去重必须保护 hold 起点、中段、首次微变、阈值和释放点；不能把所有近重复帧删除。
5. 情绪召回必须超越“伤心/愤怒”等粗标签，加入 trigger、regulation strategy、latency、beat arc、release action 和 sound punctuation。
6. 拉片必须解释 why：为什么静、为什么此刻切、为什么声音此刻响、为什么观众会这样理解，以及不同解释和失败边界。
7. Prompt 控制因果仍需真实 source prompt + 输出配对，并通过 A/B/C 或重复验证提升证据强度。
8. 自动分析是诊断与知识蒸馏工具，用户导演 verdict 仍是案例是否优秀的最高项目判断。

当前保持 K3 / 待实测：

- 自动模型对极细微眼神、肌肉张力、强忍和复杂潜台词的稳定识别精度；
- 不保留原视频时，对连续光流、极细微动作速度、真实音色与混音细节的损失边界；
- 不同表演类型最优 duration-evidence 抽样密度；
- 自动 Director Pull 与用户人工专业拉片在复杂表演上的一致率；
- 大规模 Golden Case 检索中，表演机制、导演功能、声音机制、表面风格的最优排序权重。
