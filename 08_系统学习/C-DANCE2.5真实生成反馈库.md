# C-DANCE 2.5真实生成反馈库

> 本文件保存《秽翼的尤斯蒂娅》AI电影项目中对 C-DANCE 2.5 的真实生成输入、输出观察、用户反馈、失败归因、候选模型行为与后续 targeted eval。它是**版本绑定的实测学习层**，不替代 `01_AI电影系统/AI电影系统.md` 的通用导演方法，不复制第二套剧情、角色、空间或资产事实。
>
> 项目术语：用户自 2026-08-15 起简称当前实际使用的 Seedance 2.5 为 **C-DANCE 2.5**。这里的 `C-DANCE 2.5` 是本项目用户简称，不声明平台官方更名。

# 1. 使用边界

- 只记录真实生成或真实后期验收得到的模型行为证据。
- 观察到的单次现象可以标为 `scene_verified_observation`，但由现象抽象出的可复用导演/提示词规则默认仍为 `candidate`。
- 模型版本变化、平台更新或异常漂移时，版本绑定经验进入 `needs_revalidation`。
- 本文件中的模型行为不得覆盖 canonical 剧情、角色、空间拓扑、正式资产或通用导演原则。
- 若 A/B 控制变量被污染，必须把结论标为 `confounded / inconclusive`，不得为了得到漂亮结论而强行归因。
- “更明确的提示词”不自动等于“更好的镜头”；摄影、构图、表演与动作执行必须分别验收。

## 3.2 共同剧情目标与预期动作

共同预期：

1. 凯姆已经沿建筑外立面向上运动；
2. 凯姆先经过二层临街旧木窗区域；
3. 妇女随后才开窗；
4. 原测试设计要求凯姆后脚脚尖极短暂踩中已经打开的窗扇边缘二次发力；
5. 窗扇受力下沉并回弹震动；
6. 妇女不应在开窗前完整看到凯姆，也不应与凯姆形成明确正面对视；
7. 摄影机保持建筑外部；
8. 爱丽丝只作为 VO，不获得视觉实体；
9. 不提前展示广场、菲奥奈、格兰、男孩或翅膀。

共同实验意图控制：同剧情、同7秒时长、同模型版本、同一批参考素材与生成设置；实际复盘发现**摄影机设计并未真正保持完全相同**，因此本次不能作为纯净的 SOAC 优劣结论。

## 3.3 A版提示词证据｜传统完整导演流程

以下为本轮实际用于 A 版的核心 7 秒执行稿：

```text
【镜头目的】
让观众清楚看到凯姆沿外墙快速向上搜索时，经过一扇旧木窗；一名普通中年妇女随后开窗，而凯姆后脚脚尖短暂踩中已经打开的窗扇边缘借力，再次向上弹起离开。这个片段要自然、连贯、真实，有明显受力和环境反馈。

摄影机位于建筑外部，拍摄一段底层民房外墙与旧木窗区域的连续动作。

一开始凯姆已经在外立面向上移动。他动作轻盈熟练，连续利用石块、木梁、窗框和窗台借力上行，抓点和踩点明确，身体重心不断向上转换，偶尔有自然的短距离离墙腾跃，但整体始终沿建筑外墙向上。

爱丽丝的画外音自然进入：
“那孩子的翅膀还小。不过最近猎羽查得很严。”
她本人不出现在画面里。

凯姆先从这扇临街旧木窗旁快速经过，没有停留。

随后，窗内一名普通中年妇女来到窗边，把旧木窗向外推开。她动作自然，像日常开窗，不夸张。

就在窗扇已经打开后，凯姆后脚脚尖极短暂地点中窗扇外缘。窗扇被踩得明显向下一沉。凯姆借这一点支撑立刻再次向上发力，身体继续上冲，抓向更高处支点并迅速离开窗口区域。

窗扇随后剧烈震动，木框发出真实短促的受力撞击声。妇女被突然的窗户震动惊到，产生短暂反应，但她不是提前看见凯姆，不与凯姆对视。

爱丽丝的第二句画外音接上：
“而且，翅膀会越来越大。要是让猎羽先找到，他身上的钱也会被扣下的。”

整段重点是：凯姆外立面上行真实成立；开窗和踩窗有清楚先后；窗扇的受力反馈明显；爱丽丝只存在于声音里；摄影机始终在建筑外部。
```

### A版逐帧观察摘要

成功：

- 建筑外部摄影机基本守住；
- 凯姆沿建筑外立面持续上行基本成立；
- 未切入室内；
- 爱丽丝没有因 VO 被视觉实体化；
- 未提前泄漏广场或后续人物；
- 用户确认 A 的整体构图 / 镜头观感优于 B。

失败：

- `EVENT_ORDER_FAIL`：妇女开始开窗时，凯姆仍未完成“先经过窗口区域”；三个事件在时间上发生重叠；
- `CONTACT_BINDING_FAIL`：凯姆更像踩到窗台 / 窗框附近，而非明确踩中已经打开的窗扇外缘；
- `OBSERVABLE_KNOWLEDGE_CONFLICT`：凯姆从窗口正前方经过，妇女与他空间关系过近，画面让“妇女没有看到凯姆”难以成立；
- `ENVIRONMENT_RESPONSE_WEAK`：由于关键接触没有成立，窗扇“受力下沉 → 回弹震动”的因果也没有完整成立。

## 3.4 B版提示词证据｜SOAC编译流程

以下为本轮实际用于 B 版的核心 7 秒执行稿：

```text
【镜头目的】
在7秒内清楚完成一个单镜头动作链：凯姆先经过窗口区域，妇女再开窗，凯姆后脚脚尖踩中已经打开的窗扇边缘借力，窗扇受力震动，凯姆继续沿外墙向上离开。观众必须清楚看见动作先后、脚尖与窗扇的真实接触、窗扇的受力反馈，以及爱丽丝只作为画外音存在。

【当前可见画面】
摄影机始终位于建筑外部，画面只包含旧石墙、木梁、二层临街旧木窗、窗框、窗扇、窗内中年妇女，以及沿外立面向上运动的凯姆。当前镜头不展示广场、猎羽小队、男孩或其他后续空间。

【动作事件顺序】
第一步：凯姆已经处于持续上行中。他沿建筑外立面快速移动，抓点和踩点明确，身体重心不断向上转换。相邻支点之间允许短促自然的离墙腾跃，但路线始终贴着外墙向上。

第二步：凯姆先从窗口区域上方快速经过。他没有停在窗前，也没有回头看窗内。

第三步：在凯姆已经经过之后，窗内一名普通中年妇女才来到窗边，把旧木窗向外推开。她的动作是普通日常开窗动作，不夸张，不是在追看凯姆。

第四步：当窗扇已经打开并向外形成支撑面后，仍在连续上行中的凯姆后脚脚尖极短暂地点中窗扇外缘。接触发生在一个很短的瞬间，但要清楚可见：脚尖点中 → 窗扇向下一沉 → 凯姆立刻借力抬高重心。

第五步：凯姆借这一点支撑继续向上发力，身体再次上冲，手抓向更高处支点并迅速离开窗口区域，继续沿外墙向上。

第六步：窗扇在凯姆离开后剧烈震动并回弹，木框发出短促、真实、清晰的受力撞击声。妇女只是在这时被窗户突然震动惊到，产生短暂反应。她不会在开窗前完整看到凯姆，也不与凯姆形成正面对视。

【当前可听内容】
爱丽丝只作为画外音出现，不进入画面，不被视觉实体化。
画外音自然进入：
“那孩子的翅膀还小。不过最近猎羽查得很严。”
随后接：
“而且，翅膀会越来越大。要是让猎羽先找到，他身上的钱也会被扣下的。”

同时可听见：凯姆抓踩石墙和木结构的短促接触声、衣料与空气摩擦、窗扇受力下沉和回弹震动的木质撞击声。

【最终状态】
7秒结束时，凯姆已经继续向上离开窗口区域，仍沿建筑外立面向上搜索；妇女留在被震动过的窗口前；爱丽丝仍然只有声音；摄影机始终在建筑外部。
```

### B版逐帧观察摘要

成功：

- 建筑外部摄影机基本守住；

- `CAMERA_AESTHETIC_DEGRADATION`：B 的构图更像为了记录所有事件而选择的覆盖机位，人物偏侧、窗口与人物分置，用户明确认为比 A 更像“随手拍”。

## 3.5 控制变量污染｜为什么本次不能宣称 SOAC 胜负

复盘发现 B 版额外加入了：

```text
摄影机位于民房外部，斜侧看向纵向外墙。
```

A 版没有同等的“斜侧”摄影机约束。

因此本次 A/B 除了“传统流程 vs SOAC编译流程”之外，**摄影机位置 / 朝向 / 构图策略也发生变化**。摄影机变量足以影响人物占幅、窗口位置、动作可读性和电影感，所以：

```yaml
SOAC_AB_result: confounded_inconclusive
may_claim:
  - A与B都未解决严格事件先后与窗扇微接触绑定
  - B的构图在本次实际结果中较A差
  - B的额外斜侧摄影机描述是构图差异的重要替代解释
may_not_claim:
  - SOAC总体优于传统流程
  - SOAC总体劣于传统流程
  - 更详细的VisibleIR必然导致差构图
```

## 3.6 Final-Delta 与因果归因

### 已确认事实

- A、B 都在 7 秒 C-DANCE 2.5 实际生成中完成了建筑外部上行与 VO 不实体化等部分目标；
- A、B 都没有稳定实现“凯姆完全先经过 → 妇女后开窗 → 凯姆再精确踩已打开窗扇”的复杂微动作链；
- B 更明确的事件 / 接触描述没有单独解决这个失败；
- 用户认为 A 的构图、镜头感明显优于 B；
- B 的摄影机指令与 A 不一致，A/B 控制变量被污染。

### 高置信推断

- 在本次 C-DANCE 2.5、7 秒、窗口窄空间条件下，把“高速纵向运动 + 延迟开窗 + 旋转窗扇 + 后脚微接触 + 受力反馈 + 妇女不能看见凯姆”同时耦合到一个短动作链，执行风险很高；
- 事件文字写得更显式并不保证模型能正确解出复杂时空接触关系；
- 为了让所有动作“都看得见”而改变为覆盖式摄影机，可能提升事件记录完整性，却伤害构图与电影感。

### 替代解释

- 失败可能来自参考图几何、窗扇形态、人物尺度、7秒时长、随机采样或 C-DANCE 2.5 当前版本的接触 / 时序能力边界，不应只归因于提示词；
- A 构图更好也可能部分来自随机采样，不应只归因于“正面机位”；下一轮需锁定更严格的摄影机合同才能验证。

### 反事实

如果下一轮：

1. 保持 A 的摄影机位置、朝向、景别、人物占幅和窗口构图不变；
2. 只把动作从“重叠微接触链”改成“互斥可见状态”；
3. 删除非剧情必要的踩窗接触；

则可以更干净地检验：**状态分离是否比继续增加时序文字更容易让 C-DANCE 2.5 执行正确。**

# 5. 候选学习 CD25-LESSON-002｜Temporal Exclusivity / 互斥屏幕状态

```yaml
lesson_id: CD25-LESSON-002
maturity: candidate
model_dependency: C-DANCE 2.5 / Seedance 2.5
problem:
  - “A先经过、B随后行动”仍可能被模型压成同时发生
candidate_strategy:
  - 当剧情允许时，把复杂先后关系改写为几个互斥、可见、可判定的状态，而不是继续堆“先/随后/之后”
example:
  state_A: 凯姆在窗口附近；窗关闭；妇女未出现
  state_B: 凯姆已经完全离开窗口区域；窗口附近短暂为空；窗仍关闭
  state_C: 凯姆不在窗口区域；妇女才打开窗并来到窗口
first_principle:
  - 让前一状态完成并从画面中消失，降低模型把两个动作并发融合的自由度
boundary:
  - 该策略尚未在下一轮C-DANCE 2.5真实生成中验证
  - 若剧情必须发生真实交互或连续接触，不能用状态分离逃避必要物理关系
validation:
  - 用同一摄影机合同测试原重叠链 vs 互斥状态链
```

# 6. 候选学习 CD25-LESSON-003｜可观察清楚不能替代摄影构图

```yaml
lesson_id: CD25-LESSON-003

  - 本次B为了提高动作/窗口同时可读性使用额外斜侧机位，实际构图与电影感被用户判定弱于A
operational_rule:
  - Blocking与VisibleIR负责保证事件可读，但不能为了“所有东西都看见”自动把摄影机退化成覆盖机位
  - 摄影机仍需服从导演的叙事视点、构图、景别、人物占幅、轴线和视觉重心
  - SOAC的可见域合同约束“当前能出现什么”，不等于授权编译器自行选择最方便记录动作的机位
boundary:
  - 本次A/B摄影机变量污染，不能把B构图差归因成SOAC的必然结果
validation:
  - 下一次SOAC A/B必须锁相同camera_state / camera_plan再比较
```

# 8. 当前下一步实验

当前推荐不是继续为“踩窗扇”增加提示词，而是先验证低成本反事实：

```text
保持A版较好的摄影机 / 构图合同
→ 凯姆完整经过关闭窗口
→ 凯姆完全离开窗口区域
→ 窗口短暂为空
→ 妇女才开窗
```

## 9.5 因果候选与替代解释

### H1｜单一持久锚点的状态变化，比同镜跨时代城市结构重建更容易稳定可读

观察：
- 城市“石器 → 工业”的大尺度多时代形态变化失败；
- 纪念碑“完整浮雕 → 风化裂损”的单体状态变化非常清楚。

候选机制：
- 当镜头同时要求一个高权重主角保持身份稳定时，大范围城市形态跨时代重构与主体连续性竞争较大；
- 固定单一物体作为时间锚点，只改变表面状态 / 周围人流，更容易形成稳定的时间压缩屏幕证据。

替代解释：
- 城市时代变化也可能因参考图风格锚定、30秒总信息量、随机采样或缺少每个时代的明确建筑锚点而失败；不能只归因于“模型不会跨时代”。

### H2｜极近景中存在多个相似几何语义时，目标绑定可能漂移

观察：
- 提示要求首帧是巨大头后天使环；实际先出现了另一个圆形宗教构件。

候选机制：
- 当角色 / 参考视觉同时包含多个圆形金属宗教元素时，仅写“巨大天使环”仍可能在极近特写中绑定到错误圆形对象。

替代解释：
- 也可能是模型为了制造 reveal 主动生成了新的圆形过渡物件，而非从参考图错误选择。

### H3｜单一方向动作词若没有明确起始姿态与终点，可能被参考姿态或自然动作先验改写

观察：
- “缓慢垂下一只手”实际成为向前伸手。

候选机制：
- “垂下”只描述方向意图，没有告诉模型动作开始前手在哪里、结束后手落在哪里；若参考图本身手臂姿态不同，模型可能选择更自然的伸展动作。

替代解释：
- 随机采样或参考图动作姿态也可能是主要原因。

### H4｜高显著主灾难事件可能吞掉同镜的低显著次级破坏清单

观察：
- 地平线巨浪和逃亡人群非常强；木车存在；牲畜、建筑碎片连续飞散等次级事件不清楚；模型额外生成了洪水中人物挣扎特写。

候选机制：
- 30秒多镜头中，“巨大洪峰 + 群体逃亡”已经足够满足高层“灾难 / 破坏力”，模型可能把剩余镜头预算分配给人物受灾情绪，而不是逐项执行所有环境破坏对象。

替代解释：
- 具体物理破坏也可能受到当前版本对象交互 / 大规模物理模拟能力限制。
