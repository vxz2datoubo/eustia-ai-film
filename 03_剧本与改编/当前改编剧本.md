# 第一集：当前锁定结构

## 1. 冷开场

- 尤斯蒂娅遭到追杀，约 2 分钟。
- 负责预载牢狱危险、人物脆弱与悬疑，不提前解释全部身份和因果。

## 2. 私奔男事件

- 从私奔男已经被抓住并扛回开始，不重复完整追捕过程。
- 奥兹与凯姆的对话保持底层组织的日常秩序感，而不是单纯恶人炫耀。
- 暴力后必须表现受害者身体后果与场面余震。

## 3. 爱丽丝与桥段

- 爱丽丝在桥上提前在场。
- 凯姆跳桥离开，相关信息延迟到莉莉会所回收。
- 爱丽丝问：“想要吗？想要的话就给你。”
- 凯姆回答：“用不着。”
- 爱丽丝随后单手扣住凯姆脖子并向上提，使其双脚离地。
- 趣味来自爱丽丝冷静愤怒、力量与凯姆短暂失控的反差，不使用卡通乱蹬或欢快音效。

## 4. 布道与施粥

- 底层居民把圣女布道与施粥视为同一社会事件。
- 现场包含木碗、推车、小圣像和粮食物资。
- 群众的敬爱、信仰与生存依赖同时成立，为后续对圣女的态度逆转建立落差。

## 5. 羽化病男孩

- 前置铺垫：孩童拉着母亲说布道开始。
- 凯姆需要抢在猎羽之前找到偷钱男孩，原因在后续行动与爱丽丝 VO 中自然交代，不让人物停下来上课。
- 第一集结尾仍由偷钱男孩露出翅膀形成悬念。

# 6. 凯姆高位搜索羽化病男孩｜当前确认段

状态：`CONFIRMED / CURRENT_PRODUCTION`

## 6.1 开始状态

上一段以凯姆说：

【凯姆】“羽化病吗……”

结束。

新段落开始时：

- 凯姆**已经处于攀爬途中**。
- 不再重复“羽化病吗……”的动作或对白。
- 爱丽丝本人不重新入画，只保留从上一场自然延续的画外音。
- 凯姆的行动目标是抢在猎羽之前找到偷钱男孩。

## 6.2 凯姆攀爬与爱丽丝 VO 并行

凯姆沿牢狱底层密集石木民房外立面持续向上。

动作表现为熟练、连续、轻盈并具有真实重量：手脚不断利用墙体突出的石块、横梁、窗框、窗台和屋檐等建筑支点；相邻支点之间允许自然的短距离离墙腾跃，腾跃后迅速抓住或踩住下一处支点，身体重心始终沿外墙路线向上推进。动作接触短、停顿少、落点明确，整体形成连续的纵向跑酷式攀爬。

爱丽丝 VO 与动作同时进行：

【爱丽丝 VO】
“那孩子的翅膀还小。不过最近猎羽查得很严。”

凯姆没有回答，继续向上扩大搜索视野。

【爱丽丝 VO】
“而且，翅膀会越来越大。要是让猎羽先找到，他身上的钱也会被扣下的。”

这段 VO 的功能是解释凯姆为什么必须抢先找到男孩；不切治愈院、押送、猎羽抓捕等额外解释画面。

## 6.3 二层临街木窗

凯姆经过一扇二层临街木窗。

一名普通中年妇女从屋内推开窗。

凯姆不停留，脚尖极短暂地点在刚打开的窗扇或窗台边缘，完成第二次向上的发力，继续攀升。

木窗受力后明显震动，发出短促木响。

妇女被吓了一下，但第一反应不是马上找到凯姆。由于远处钟楼 / 圣女平台正在进行布道与施粥，她先自然望向那个方向。

随后，她才察觉头顶高处刚刚掠过异常黑影，抬高视线。

此处镜头只保留高处一闪而过的局部黑影和运动痕迹，凯姆的完整身影稍后再被重新建立，让异常先被感知、来源稍后才被理解。

## 6.4 菲奥奈巡查｜最新确认

切到市集 / 布道施粥广场附近的菲奥奈。

镜头切到菲奥奈之前，她已经在带队巡查，维护人流、排队和现场秩序。

她身边 / 身后至少有两名队友：

- 一人为副队长；
- 至少另一人为与副队长同一制服体系的队员；
- 队友也应处于真实执勤状态，而不是静态陪衬。

菲奥奈被高处细微异常短暂吸引：

- 先产生一点疑惑；
- 眼神轻微向上偏移；
- 随后有一个很轻的抬头观察。

她只获得“高处似乎有异常”的模糊信息，注意力仍以现场职责为主。

恰在这时，旁边排队区域出现一名插队男子。副队长或同制服队员立即伸手拦住 / 控制住男子，周围出现轻微秩序骚动。

菲奥奈随即回头，把注意力重新拉回自己本来承担的现场职责，转身协调处理。

此镜头同时完成：

1. 轻微预载“高处可能有异常”；
2. 交代菲奥奈为什么在这里；
3. 用行动而非解释对白证明她的队长职责；
4. 通过队友数量、制服、谁先控制、谁最终协调建立组织层级；
5. 保持凯姆寻找男孩仍是本段唯一一级主线。

## 6.5 凯姆登顶

重新回到凯姆。

他接近一栋约四层高的普通民房顶部，抓住屋檐完成最后一次借力，翻上屋顶。

翻上屋顶后顺着真实惯性前移半步，短暂压低重心或用一只手触碰屋面稳定身体，随后立即起身前往屋顶边缘。

凯姆迅速来到屋顶边缘。

下方逐渐展开密集民房、狭窄街道、棚位与向广场流动的人群；更远处进入市集 / 布道施粥广场，教堂钟楼和圣女平台位于远中景。

凯姆从高位快速扫描人群：先扫一侧，短暂停顿，再转向另一侧；最后可在某个方向略微停住。

本段结束前保持以下信息状态：

- 偷钱男孩与其翅膀仍留在镜外，翅膀信息未揭示；
- 凯姆仍处于搜索状态，尚未确认目标；
- 猎羽尚未在画面中完成对男孩的抓捕；
- 治愈院 / 押送等后续内容继续留给后面的剧情；
- 菲奥奈只留下对高处异常的轻微职业警觉，现场职责仍占据她的主要注意力。

第一集结尾“男孩露翅”继续作为悬念回收。
