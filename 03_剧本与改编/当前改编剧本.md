# 第一集：当前锁定结构

## 1. 冷开场

- 尤斯蒂娅遭到追杀，约 2 分钟。
- 负责预载牢狱危险、人物脆弱与悬疑，不提前解释全部身份和因果。

## 2. 私奔男事件

- 从私奔男已经被抓住并扛回开始，不重复完整追捕过程。
- 奥兹与凯姆的对话保持底层组织的日常秩序感，而不是单纯恶人炫耀。
- 暴力后必须表现受害者身体后果与场面余震。

## 3. 爱丽丝与桥段

- 爱丽丝在桥上提前在场。
- 凯姆跳桥离开，相关信息延迟到莉莉会所回收。
- 爱丽丝问：“想要吗？想要的话就给你。”
- 凯姆回答：“用不着。”
- 爱丽丝随后单手扣住凯姆脖子并向上提，使其双脚离地。
- 趣味来自爱丽丝冷静愤怒、力量与凯姆短暂失控的反差，不使用卡通乱蹬或欢快音效。

## 4. 布道与施粥

- 底层居民把圣女布道与施粥视为同一社会事件。
- 现场包含木碗、推车、小圣像和粮食物资。
- 群众的敬爱、信仰与生存依赖同时成立，为后续对圣女的态度逆转建立落差。

## 5. 羽化病男孩

- 前置铺垫：孩童拉着母亲说布道开始。
- 凯姆需要抢在猎羽之前找到偷钱男孩，原因在后续行动与爱丽丝 VO 中自然交代，不让人物停下来上课。
- 第一集结尾仍由偷钱男孩露出翅膀形成悬念。

# 6. 凯姆高位搜索羽化病男孩｜当前确认段

状态：`CONFIRMED / CURRENT_PRODUCTION`

## 6.1 开始状态

上一段以凯姆说：

【凯姆】“羽化病吗……”

结束。

新段落开始时：

- 凯姆**已经处于攀爬途中**。
- 不再重复“羽化病吗……”的动作或对白。
- 爱丽丝本人不重新入画，只保留从上一场自然延续的画外音。
- 凯姆的行动目标是抢在猎羽之前找到偷钱男孩。

## 6.2 凯姆攀爬与爱丽丝 VO 并行

凯姆沿牢狱底层密集石木民房外立面持续向上。

动作表现为熟练、连续、轻盈并具有真实重量：手脚不断利用墙体突出的石块、横梁、窗框、窗台和屋檐等建筑支点；相邻支点之间允许自然的短距离离墙腾跃，腾跃后迅速抓住或踩住下一处支点，身体重心始终沿外墙路线向上推进。动作接触短、停顿少、落点明确，整体形成连续的纵向跑酷式攀爬。

爱丽丝 VO 与动作同时进行：

【爱丽丝 VO】
“那孩子的翅膀还小。不过最近猎羽查得很严。”

凯姆没有回答，继续向上扩大搜索视野。

【爱丽丝 VO】
“而且，翅膀会越来越大。要是让猎羽先找到，他身上的钱也会被扣下的。”

这段 VO 的功能是解释凯姆为什么必须抢先找到男孩；不切治愈院、押送、猎羽抓捕等额外解释画面。

## 6.3 镜头二｜二层临街木窗三步动作链

摄影机提前停留在一扇二层临街旧木窗附近。

一名普通中年妇女原本就在屋内做自己的事情，她自然走到窗边准备开窗向外看或通风。

这一处的动作顺序严格为三步，不能合并成同时发生：

1. **凯姆先经过。** 凯姆的身体先从窗边画面边缘高速向上掠过，连续攀爬没有停下。
2. **妇女随后开窗。** 凯姆已经先掠过后，妇女才把旧木窗向外推开。
3. **脚尖第三步借力。** 凯姆仍处于连续向上的运动链中，后脚脚尖极短暂地点在已经打开的窗扇边缘，以此完成一次向上的二次发力，身体马上继续冲向更高处。

木窗突然承受力量后明显向下一沉并剧烈震动，木框产生短促、真实的撞击声。

凯姆随即离开这一镜头的主要可见区域，画面不把借窗动作延长成独立展示。

爱丽丝第二句画外音自然继续：

【爱丽丝 VO】
“而且，翅膀会越来越大。要是让猎羽先找到，他身上的钱也会被扣下的。”

妇女顺着自己原本的生活注意力向远处市集、教堂钟楼与圣女布道方向看去；她的视线成为下一镜切入广场的视觉桥梁。

## 6.4 镜头三｜广场章节入口、菲奥奈小队职能介绍与后续因果预载

顺着妇女的视线 / 主观观察方向切入市集与布道施粥广场附近。

这一镜头不是“凯姆主线里的次级插曲”，而是当前小章节进入教堂前公共空间后的**场景重新锚定与角色职能介绍**：让观众迅速知道这里正在发生什么、哪些角色已经在场、猎羽小队如何工作，并为后续偷钱男孩引发骚动后猎羽能够迅速赶到建立前置因果。

菲奥奈和自己的小队已经处于正在进行的巡查工作中。镜头切到他们之前，他们就已经在维护人流、排队、通道和现场秩序。

菲奥奈身后跟着副队长和队员。周围有端着木碗的居民凌乱穿行，队员查看队伍、通道与人流，小队整体处于真实工作状态。

菲奥奈短暂抬头，看向刚才凯姆爬过的屋顶方向。

就在这一瞬间，身后的副队长发现一名大叔抢走一个小男孩的面包后开始逃跑。

副队长对犯罪行为高度敏感并带有明显厌恶，性格冷硬、不友好；他的角色职能通过即时行动建立，而不是靠说明对白解释。

现场动作快速推进：副队长准备追上抢面包男子，但前方大量平民挡住地面去路；他随即半蹲起跳到居民楼二楼外墙，借建筑外墙瞬间转移路线，双腿对墙面一蹬后向逃跑男子俯冲，抓住对方并将其控制。

摄影机在这一小段保持紧迫的现场手持感，重点读清副队长的判断、换路线、借墙发力和抓捕结果，不把摄影机本身变成表演主体。

菲奥奈立即把注意力从高处收回，走近已经完成控制的副队长。副队长把抢面包男子提溜起来，菲奥奈进入现场并承担整体处理、协调与后续判断。

这一小段在极短篇幅内同时建立：

1. 教堂前 / 市集 / 布道施粥广场已经进入当前章节；
2. 菲奥奈为什么在这里，以及她承担的是全局巡查、协调和管控；
3. 副队长是行动反应快、痛恨犯罪、手段直接而性格阴冷不友好的执行者；
4. 队员与群众都已有各自正在进行的工作和生活，不是等待主角出现才启动；
5. 猎羽小队就在这一区域持续巡逻，因此后续偷钱男孩制造骚动时，他们能够迅速响应有了明确因果基础；
6. 高处凯姆只作为菲奥奈短暂注意到的异常之一，本镜头的核心职责是完成新空间与猎羽角色系统的章节介绍。

## 6.5 镜头四｜凯姆登顶后的宏观空间建立

镜头三完成教堂前广场的人物、秩序与职能介绍后，重新回到凯姆。

他接近一栋约四层高的普通民房顶部，抓住屋檐完成最后一次借力，翻上屋顶。

翻上屋顶后顺着真实惯性前移半步，短暂压低重心或用一只手触碰屋面稳定身体，随后立即起身前往屋顶边缘。

凯姆迅速来到屋顶边缘。

这一镜头承担前一镜没有承担的**宏观空间建立**：从凯姆高位视角展开密集民房、狭窄街道、棚位与向广场流动的人群；更远处进入市集 / 布道施粥广场，教堂钟楼和圣女平台位于远中景。

凯姆从高位快速扫描人群：先扫一侧，短暂停顿，再转向另一侧；最后可在某个方向略微停住。

- 猎羽尚未在画面中完成对偷钱男孩的抓捕；
- 治愈院 / 押送等后续内容继续留给后面的剧情；
- 菲奥奈只获得对高处异常的短暂注意，随后回到自己的现场职责；
- 猎羽小队已经被明确建立为当前广场正在持续巡逻和处理犯罪 / 秩序事件的在场力量，为后续快速响应做因果预载。

第一集结尾“男孩露翅”继续作为悬念回收。

# 7. 后续真相改编锁定｜初代圣女伊莲、神与尤斯蒂娅

状态：`CONFIRMED / FUTURE_REVEAL_CANON`

## 7.1 神令伊莲成为天使的动机｜项目改编新增

- 保留原作“伊莲虔诚祈求、神让她自己成为天使并守护人类”的基本事件，但补充神的性格与动机。
- 神不是单纯慈悲地回应祈祷，而带有明显的**惩罚性、冷酷的讥讽感与近似恶趣味的试炼意味**。
- 神对人类的判断是：人类长期只知道向神和天使祈求，把责任交给更高存在，却不愿自己承担拯救世界的代价。
- 伊莲的虔诚确实被神看见，但神的回应近似于：“既然你们人类只会祈求，那么就由你这个人类自己去承担天使的职责。”
- 因此“让伊莲成为天使”同时具有三层意义：回应她的诚心、把责任强行返还给人类、以近乎戏弄的方式让最虔诚的祈祷者亲自承担祈祷所要求的全部代价。
- 后续演出不得把神简化成普通反派或单纯残忍暴君；他的危险感来自超越人类尺度的价值判断、惩罚逻辑与对人类苦难的冷距离。
- 该动机属于本项目电影改编确认项，不得误称为原作逐字设定。

## 7.2 伊莲为何创造尤斯蒂娅｜原作真相保留

- 伊莲成为天使并帮助人类后，反而遭到人类背叛、囚禁并被长期抽取力量；诺瓦斯的真实浮空机制与圣教会公开神话存在重大差异。
- 在约五百年的漫长囚禁中，伊莲最初并未立即憎恨人类；反复的欺瞒、背叛和对其力量的利用逐渐磨灭了她对人类的信任。
- 当后来的人类权力者为私欲大量滥用天使力量，并最终让“人类曾背叛她也要维持的城市”再次因人类自身过失走向坠落时，伊莲最后的希望被击碎。
- 此时伊莲已经被囚禁和榨取到几乎无法亲自行行动，因此创造了天使之子尤斯蒂娅，让她成为自己的代理者。
- 尤斯蒂娅诞生时承载的原始使命不是“继续守护人类”，而是：**替已经无法行动的伊莲结束人类，让背叛她的人类走向灭亡，并让伊莲漫长的痛苦得到解脱。**
- 终盘初代伊莲称尤斯蒂娅为“我的孩子”，因此两者在剧情与情感上按“创造者 / 母亲”关系处理，而不是普通同类天使关系。

## 7.3 第一集信息保护

- 第一集达尔布道仍只呈现圣教会公开神话，不提前揭露上述真实机制。
- 第一集历史视觉不得客观证明“历代圣女的祈祷能量直接托住诺瓦斯”；应通过达尔叙述与画面并置，让观众自然接受公开解释，同时为终盘真相保留翻转空间。
- 初代伊莲在第一集公开神话画面中先以**无翅膀的人类圣职者形态**出现，避免提前泄露其后来成为天使的真相。
- 后续终盘再揭示其天使身份、长期囚禁与残骸形态，并通过稳定的面部骨相 / 标志性视觉符号完成第一集到终盘的角色回收。
