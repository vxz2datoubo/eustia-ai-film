# 示范片段（仅为结构示例，不是正式 Golden Case）

> 情境：一个女人刚听到非常伤人的话。画面没有台词。她长时间看着对方，几乎不动，随后眼眶慢慢红、嘴部开始绷不住，最后突然很重地关门。

## 简化导演拉片

**剧情功能**：不是告诉观众“她伤心”，而是让观众经历“伤害进入身体后，她努力不让它表现出来”的时间过程。

**表演弧线**：`receive → freeze → hold/contain → leakage → decide → release/cut_off`。

**静止为什么不是空白**：前半段长时间几乎不动，证明她并非立即宣泄，而是在压住反应。持续时间本身让观众等待一个答案，并把注意力从大动作转向眼睛、嘴、呼吸和肌肉张力的微小变化。如果直接从受伤切到红眼，观众得到的是“结果”；保留 hold，观众经历的是“过程”。

**阈值**：眼眶首次明显红润、嘴部开始失去控制，是内在压力第一次泄漏到可观察表演上的阈值。

**关门与声音**：最后的猛关门不是简单“生气动作”。如果前面声场稀疏、动作克制，门响会因为动态范围突变而获得额外冲击。它可以同时承担情绪释放、决定落地、关系切断和场景句号。真正要学的不是“伤心戏要摔门”，而是“长时间 containment 之后，用单一明确动作 + 声音 punctuation 收口”。

**召回机制**：以后用户说“被伤到以后很平静、后劲重、不是马上哭、最后一个动作收掉”，应优先召回 `restrained_hurt / delayed_reaction / low_motion_high_information / containment_and_leakage / strong_action_release / sound_punctuation`，而不是只按“伤心女人”匹配。

**失败边界**：如果前置伤害不足、演员微表情不可读、镜头太远、hold 没有任何内部变化、或最后动作没有前面积压，长时间静止可能只显得拖；如果角色性格本就外放爆发，则该机制未必成立。
