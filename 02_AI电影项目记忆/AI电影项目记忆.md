# 3. 当前激活导演规则

- 剧情、人物动机、因果和主题优先于镜头炫技。
- 先做长线剧情诊断，再做单场导演设计。
- 先设计空间和演员行动，再选机位、景别、运镜、灯光和剪辑。
- 旁白优先改成对白、动作、道具和画面表达。
- 每镜必须承担明确功能。
- 镜头目的先行，观众认知先行。
- 重要动作必须设计预备、发生、后果和反应。
- 不把抽象情绪直接写成表情词。
- 不把角色行为拍成与利益、职业、社会位置和风险偏好冲突的方便动作。
- 正式AI视频提示词使用最小充分约束，不堆同义质量词。

# 4. 导演研究前置协议

正式剧情导演任务执行：

```text
检索母本与足够前后文
→ 核对当前改编层、角色、场景和连续性
→ 分析伏笔、回收、人物弧光、悬念、节奏、主题和下一场推动
→ 把问题转成具体导演研究问题
→ 研究专业来源

→ 设计空间与演员行动
→ 设计镜头、灯光、声音和剪辑
→ 编译为AI可执行文本
→ 回归检查
```

专业资料服务项目，不把项目拍成课程示范片。没有必要时不为每个局部措辞发动大规模研究。

# 8. 绯灯街社会结构

## 8.1 命名

- 正式改编名：绯灯街
- 人物口语名：舞女街
- 原作检索名：娼妇街、娼馆街
- 制作期旧称：歌舞街、仓库街

所有旧称指向同一片复合街区，不得拆成多个独立地点。

## 8.2 功能共存

绯灯街同时容纳：

- 娼馆、成年性交易、舞女、陪酒、歌舞厅和卖身契
- 酒馆、药铺、面包铺、杂货摊和底层住房
- 仓储、装卸、货物转运和商铺后勤
- 不蚀金锁的上纳金、保护和暴力秩序
- 爱丽丝为娼妇和底层居民提供的医疗
- 贫穷、剥削、互助、幽默、劳动和日常生活

不得情色化，也不得为了平台规避而漂白。

## 8.3 角色交叉关系

### 爱丽丝

- 曾接近进入娼馆行业，被凯姆赎出
- 后在绯灯街行医
- 她的医者身份、被赎经历、对凯姆的依赖和街区经济不可拆开理解

### 梅尔特

- 曾是娼馆街最有人气的娼妇
- 赎身后经营蔷薇酒馆
- 她代表艰难而少数的阶层流动路径，不得拍成普遍成功神话

### 私奔事件

卖身契、金锁秩序、客人带走舞女、上纳金和惩罚属于同一制度链，不是单纯爱情骗局或黑帮斗殴。

# 9. 锁定空间拓扑

## 9.1 总路线

```text
莉莉会所
→ 绯灯街S形生活商业街
→ 蔷薇酒馆
→ 主街道
→ 横向高架石桥跨越主街
→ 市集与布道施粥广场
→ 教堂钟楼
→ 钟楼后方的关所底层入口
→ 关所内部唯一受控上行通道
```

## 9.2 莉莉会所内部

- 入口前台在左侧
- 屏风
- 一楼卡座
- 小型舞区
- 楼梯偏左
- 二楼办公区可俯瞰一楼

## 9.3 绯灯街

- S形石板街
- 生活、商业、娱乐、仓储和住房混合
- 蔷薇酒馆位于转角或出口附近
- 不得被设计成单功能现代红灯区

## 9.4 桥与主街

- 桥在上，主街在下
- 桥不是同平面十字路口
- 桥下保留货运、推车、仓储补给和低层通道
- 桥面通往更公开的市集、布道和钟楼 / 关所方向；具体方向与可达路线服从 canonical 地图

## 9.5 市集与教会高塔

- 市集两侧摊位和堆货，中部保留通行与集会
- 布道与施粥同场发生
- 高塔前有长石阶，突出制度和神圣性
- 钟楼后方是关所底层入口；进入关所内部后才通过唯一受控的四方回旋楼梯上升至中层
- 检查岗、厚重石门、封闭拱口和集散平台属于关所内部通道；教堂钟楼不承担上行交通

# 10. 布道施粥

- 底层居民将布道与施粥视为同一社会事件
- 现场包含小圣像、木碗、推车和食物分发
- 群众对教会具有真实敬爱和生存依赖
- 后续“杀圣女”必须与这一前置关系形成巨大反差
- 不能只拍成宗教演讲，生存优先

# 11. 观众认知时差与延迟揭示

正式区分悬念、同步发现、知觉惊异和结果先于原因的回溯重建。

奥兹暴力场景可采用：

```text
日常基线
→ 感官刺激或结果先出现
→ 观众短暂无法解释
→ 行动者、动机或完整空间后补
```

但不得破坏当前动作理解和道德归属。

# 12. 镜头空间分层编译

复杂镜头必须明确摄影机、前景、主体、后景、环境、遮挡、动作归属、时间顺序、声音来源和最终状态。

正式顺序：

```text
切镜或不切镜
→ 景别
→ 摄影机位置和方向
→ 前景
→ 主体与后景
→ 遮挡
→ 动作时序
→ 声音
→ 最终构图
```

# 13. 反应、视线和可见面

- 摄影机位于人物前方、侧方或后方时，只能看见对应的脸面。
- 反应镜头不必同时承担空间确认。
- 非互惠关系不能误用普通正面对视反打。
- 私奔男试图连接而凯姆拒绝时，使用私奔男正脸反应、关系镜头和凯姆侧后方动作镜头。
- 不得用剪辑制造凯姆与对方正面对视的错误空间。

# 14. 渐进式画面侵占

用于不依赖吼叫、狞笑和音乐的威胁：

```text
开放画面
→ 威胁者占幅扩大
→ 负空间缩小
→ 肩膀进入前景
→ 部分遮脸
→ 只保留关键反应
```

强度主要放在调度、透视、遮挡和画面主权转移中。威胁者越克制，暴力秩序越可信。

## 17A.3 本轮演化记录

### 2026-08-03｜Seedance多机位资产与整体渲染

- “不要重新设计场景”可能被模型理解为不允许生成新角度，因此改用正向空间与一致性描述。
- 左右90°实测容易退化成45°，方向要求应明确摄影机围绕同一中心转到正侧位置，必要时增加白模。
- Seedance具备白模参考渲染能力，外观已成立时由参考图承担材质、光影、人物质感、天气和粒子氛围。
- 质量词不代替任务分工；白模负责结构与运动，参考图负责原有整体外观，Seedance负责最终生成式渲染。
