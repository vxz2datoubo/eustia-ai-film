# AI电影项目记忆

本文件是项目专属长期事实、稳定审美偏好、历史裁决、生产经验和失败模式的唯一可写索引。它不复制当前剧本、角色全表、资产全表、地图拓扑或通用导演理论；这些内容分别服从 PROJECT_INDEX 指定的唯一主档。

## 1. 启动、存储与裁决

新会话或重要剧情、角色、场景、完整分镜、迁移、审计与本文件更新后的首次使用，应先读取 PROJECT_INDEX.yaml，再按 read_sets 读取本文件的相关章节。普通续作仅检索命中章节与当前剧本、角色、场景、地图、资产、连续性。

权威顺序：

    用户当前明确确认
    → GitHub verified 当前剧本、角色、地图、资产、连续性
    → 本项目记忆的未冲突项目事实
    → 外部母本和证据
    → AI电影系统
    → Memory 与模型一般知识

所有修改原地写入固定文件名；Git commit/tag 承担历史版本。ChatGPT Library / 本地只读层保留媒体、游戏母本、PDF、原始证据和历史快照；Memory 仅作提醒索引。项目应保留可恢复的异地或离线备份与哈希，但备份不参与默认检索。全新会话恢复测试必须能从项目入口定位当前主档并继续工作。

## 2. 项目身份与目标

- 项目：秽翼的尤斯蒂娅 AI动画 / AI电影化改编。
- 用户角色：导演、总创意决策者、最终审定者。
- AI角色：导演助理、编剧分析、摄影分镜顾问、AI生成编译器、连续性管理和系统学习执行者。
- 默认语言：中文；单集目标约十分钟，叙事密度优先于时长填充。
- 项目定位：成人向社会悲剧，以恋爱、悬疑、政治和宗教为叙事外衣。
- 核心主题：所有人都有不得已，也都在不同程度上制造悲剧。

原作完整母本为外部只读证据。当前正式改编层优先于母本；差异应可追溯，但 public GitHub 不复制原作全文。

## 3. 稳定改编与美学偏好

- 剧情、人物动机、因果与主题优先于镜头炫技。
- 先做长线剧情诊断，再设计单场；先设计空间和演员行动，再选机位、景别、运镜、灯光和剪辑。
- 旁白优先转为对白、行动、道具和画面；每镜都有明确职责。
- 重要动作需要预备、发生、后果和反应；角色行为不得为了方便剧情而违背利益、职业、社会位置与风险偏好。
- 正式提示词采用最小充分约束，不堆叠同义质量词；失败只修失败维度。

视觉底座：

- 真人实拍与电影截图质感，真实摄影机成像；
- 真实皮肤、头发、布料、旧木、石材与金属，复杂但清晰的材质层次；
- 自然景深、真实曝光、稳定黑位、柔和高光与清楚的冷暖关系；
- 正片默认 16:9，特殊资产按用途决定比例；
- 排除游戏CG、插画、数字绘画、塑料皮、过度 HDR、无逻辑锐化和伪细节。

## 5. 项目生产方法与实测经验

- Seedream 负责身份、服装、场景、道具、材质、首尾帧与局部图像修复；Seedance 负责动作、表演、摄影机、声音与连续时间；复杂几何先做白模或深度图。
- 4–15 秒是稳定生成单元；30 秒须有清楚结构，不能为了长度塞满随机动作。
- 场景资产母片优先空间一致、截图稳定、多机位互证和正 90 度机位准确；正式剧情镜头另按叙事目的设计。
- 当参考图外观已经成立时，整体渲染应继承其材质、人物、服装、光照、天气、粒子与氛围，不逐项重新设计。
- 正反打或新机位不轻易锁死光照、阴影与遮挡方向；必要时以白模承担隐藏几何。
- 多机位的正侧要求易退化为 45 度，应以正向空间描述、明确摄影机绕同一中心转到正侧、并在需要时提供白模。
- 白模负责结构与运动；参考图负责既有外观；Seedance 负责最终生成式渲染。
- 同一素材不要反复套娃生成；回到干净母版、分区重建、蒙版合成，最后一次全局调色、锐化、颗粒与放大。

## 7. 学习与写回

项目经验先按 candidate、scene_verified、project_verified、general_stable 分级；conflicted、needs_revalidation、deprecated 保留为旁路状态。一次成功不能自动上升为通用规律。模型或工具版本变化会触发依赖性经验复验。

写回归属：

    通用导演与AI生成方法 → AI电影系统
    项目长期事实与项目偏好 → 本文件
    当前改编剧情 → 当前改编剧本
    角色行为与关系 → 角色与表演设定库
    场景局部属性 → 场景与空间设定库
    空间拓扑 → 00_项目地图文件
    正式媒体资产 → 视觉资产登记库
    当前镜头状态 → 连续性与当前生产状态
    反馈与证据 → 对应学习或证据主档
    无法裁决的问题 → UNKNOWN_REGISTRY
