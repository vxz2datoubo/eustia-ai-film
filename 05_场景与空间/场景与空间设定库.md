# 场景与空间设定库

本库是场景时代、建筑风格、材质、装饰、光照、天气、家具道具、使用痕迹、局部功能、摄影基线、场景执行约束及关联 Asset ID 的唯一可写文字库。空间拓扑、方向、邻接、上下层、桥上桥下、入口出口、可达路线、人流货流和镜头空间连续性只由 00_项目地图文件.md 裁决。

如本文件出现与地图冲突的旧表述，地图优先；本库只修正局部美术和使用信息，绝不建立第二套拓扑。

## 1. 世界空间总则

- 架空中世纪晚期空中都市的牢狱 / 平民区底层。
- 中世纪手工时代材质：旧石、旧木、灰泥、铁件、粗布、油布、麻绳、烟尘与使用磨损。
- 底层城市可被悬崖、岩壁和高墙包围；不默认出现现代物品、现代道路、电灯或开阔现代天际线。
- 建筑比例、可见材料、道路边界和局部功能必须稳定；场景是社会机制与权力结构的一部分，不是装饰背景。
- 电影质感为真实摄影机、物理正确光照、克制调色、自然旧化与可读空间；避免游戏CG、塑料材质、插画化纹理和过度HDR。

### 1.1 场景执行通则

场景提示或资产说明先给整体风格总览，再给当前可见区域、结构、物件、光线、功能、人物动线和镜头目的。严格顶视、复杂遮挡、桥上桥下、多人路径或长镜头优先由地图、白模、YAML 或深度图锁定几何；本库不替代它们。

场景资产的职责分离：

- 正式图片：材质、局部外观、方向或机位职责。
- 白模和深度图：空间、站位、遮挡、路径和机位。
- 视频：时间、动作、运镜和环境运动。
- 普通生成图或测试视频：默认临时，不自动成为正式资产。

用户明确确认后才在 06_视觉资产/视觉资产登记库.md 建立 active 或其他正式状态；派生图不得覆盖原始空间母版。

## 2. 场景节点

### 2.1 莉莉会所

性质：旧欧洲中世纪晚期风格的底层灰色歌舞娱乐场所，不是现代夜店或贵族宫廷。可有限采用屏风、帘子、花格、流苏和红木色细节，但欧洲中世纪主体不能被替换。

局部设定：

- 入口附近有接待与屏风；一楼有多组卡座和小型舞区。
- 楼梯处于偏左或左中区域；二楼办公区拥有俯瞰一楼的管理视线。
- 木材、暗红棕、烟熏、磨损金属与有限烛灯/油灯建立体面、暧昧、贫穷和旧化并存的氛围。
- 功能包括歌舞、陪酒、灰色消费、金锁上纳金、信息流和雇佣；不可仅拍成华丽背景。
- 客人、舞女、工作人员与金锁成员的可活动区、视线和权力不相同；楼梯是公开营业与后台管理的转换节点。

### 2.2 绯灯街

绯灯街是S形石板复合街区，商铺、住户、成人劳动、酒馆、医疗、仓储与装卸混合。密集房屋之间必须保留可信的行走巷道与生活痕迹。

- 建材：旧石基、修补灰泥、歪斜木梁、窄窗、门帘、褪色招牌、木箱、手推车和货物堆叠。
- 气质：体面、暧昧、贫穷、幽默、剥削、互助、劳动与生活同时存在。
- 光照：日间以狭窄街谷反射光、屋檐阴影和局部窗光为基线；夜间如需使用烛火、油灯或店内暖光，应保持低层生活感。
- 相关事实和别名由角色库与项目记忆补充；地理位置、出入口、朝向和路线服从地图。

### 2.3 蔷薇酒馆

蔷薇酒馆是生活区、信息流与主街出口之间的过渡功能节点，由梅尔经营。中文招牌为 蔷薇酒馆。外观和内景应提供经营者对自身空间的主导权：可见的服务台、酒具、旧木桌、杯盘、库存与日常维护痕迹，而非只作端酒背景。

### 2.4 主街与高架石桥的局部视觉

拓扑和方向由地图锁定；本库只规定视觉与使用基线：

- 主街下层应保留货运、推车、仓储补给、步行和低层道路的连续生活痕迹。
- 石桥以风化石材、承重拱券、磨损桥面、潮痕、尘土与局部苔藓体现长期使用。
- 桥下需有阴影、声学压缩、货物边缘和可读的通行空间，不应成为无功能黑洞。
- 桥面与桥下可使用不同的光照、风和人群密度，但资产的方向标签服从地图与 Asset Registry。

### 2.5 市集与布道施粥广场

市集广场是交易、布道、施粥、消息传播和群众集聚的局部功能场。

- 两侧可见棚位、货物、木桌、推车、木碗、小圣像、麻袋、木箱与棚布。
- 中央应保留可用于排队、疏散、布道、施粥和巡查的空隙，不能用无目的摊位堵死。
- 材质和使用痕迹包括粥锅蒸汽、木器磨损、湿泥、谷物碎屑、推车轮迹、布棚旧化和不同阶层衣物。
- 群众行为同时来自信仰、生存、交易和秩序维护，不能拍成纯礼仪摆拍。
- 教堂钟楼相关的正面、左视、右视资产职责由视觉资产登记库定义；钟楼和关所的空间关系由地图定义。

### 2.6 教堂钟楼与关所

钟楼是宗教、公共仪式和视觉地标，可表现长石阶、石砌塔身、钟体、岁月侵蚀、旗帜与仪式性集聚。关所是相邻但不同的制度性空间；本库不将二者合并。

关所内部局部气质可包括检查岗、厚重石门、封闭拱口、栏杆、集散平台、磨损石阶、行政标记与受控交通的压力。其入口、垂直交通、可达性和与钟楼的准确关系只引用地图，不在本库再写拓扑副本。

## 3. Seedance / Seedream 场景约束

- Seedream 用于稳定建筑材质、局部装饰、关键机位和干净场景母版；Seedance 用于人流、风、旗帜、蒸汽、动作、运镜和连续时间。
- 外观已成立时，整体渲染应保持同一建筑身份、材料逻辑与时代，不重新设计场景。
- 多机位应声明本次资产只负责哪个方向/高度/时间/天气职责；不要把方向资产水平翻转冒充其配对视图。
- 严格几何或正交资产先用无人物测试确认机位，再加入人物；人物表演镜头不可反向推翻已锁定空间。
- 允许的变化：天气、光照、低显著度群众、临时摊位、合理旧化和剧情允许的布置。
- 禁止的变化：现代化改造、改变建筑时代、改变 Asset ID 角色、将普通生成图提升为正式默认、用局部美术推翻地图。
