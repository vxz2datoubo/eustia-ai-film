# 场景与空间设定库

> 本文件维护固定场景的性质、材质、功能、氛围、固定结构、道具、光源、局部动线和场景资产关系。空间拓扑、相邻关系、入口、方向、桥路高低和真实可达路线的唯一权威为[00_项目地图文件](00_项目地图文件.md)。
> 场景提示词必须先写“整体风格总览”，再写具体区域、方向、结构、物件、光线、功能和人物动线。

> GitHub-first reconcile（2026-08-12）：本文件保留源文件的场景知识。第2、6、8、9节的路线/拓扑表述只作为局部历史与提示词语境；如与地图冲突，地图优先，并按地图的钟楼—关所裁决解释。

# 1. 世界空间总则

- 架空中世纪晚期空中都市底层
- 中世纪手工时代材质
- 底层城市被悬崖、岩壁和高墙包围
- 默认不出现现代物品、现代道路、电灯和开放天空
- 建筑比例、道路连通、楼层高低和相邻关系必须稳定
- 场景是社会机制和权力结构，不只是装饰背景

# 2. 总拓扑（局部历史摘要；地图唯一权威）

# 3. 莉莉会所

## 性质

旧欧洲中世纪晚期风格为主体的底层灰色歌舞娱乐场所。不是现代夜店，不是贵族宫廷。可少量加入中式屏风、帘子、花格、流苏和红木色细节，但不得改变欧洲中世纪主体。

## 固定空间

```yaml
entrance:
  reception: left
  screen: near_entrance
ground_floor:
  booths: multiple
  dance_area: small
stair:
  position: left_of_center
second_floor:
  office_overlook: true
```

## 功能

- 歌舞、陪酒与灰色消费
- 金锁上纳金、信息流和雇佣节点
- 不能只作为华丽背景

# 4. 绯灯街

- S形石板街
- 商铺、住户、娼馆、酒馆、医疗、仓储和装卸混合
- 房屋密集但保留可行走巷道
- 体面、暧昧、贫穷、旧化和生活感并存
- 社会功能详见[AI电影项目记忆](../02_AI电影项目记忆/AI电影项目记忆.md)第8章；拓扑与方向详见地图

# 5. 蔷薇酒馆

- 位于绯灯街转角或外出节点
- 经营者：梅尔特
- 中文招牌：蔷薇酒馆
- 是生活区、信息流和主街出口之间的过渡节点

# 6. 主街与横向高架石桥

```yaml
bridge:
  elevation: upper
  relation: OVER main_street
main_street:
  elevation: lower
  relation: UNDER bridge
intersection:
  same_level_crossroad: forbidden
  bridge_deck_continuous: true
  street_occluded_under_bridge: true
```

- 桥面通往市集
- 桥下仍为仓储、推车、运输和通行
- 生成俯视图时必须明确桥上路下

# 7. 市集与布道施粥广场

- 两侧摊位和堆货
- 中央通道兼具通行、集会和布道
- 木桌、推车、木碗、小圣像、麻袋、木箱和棚布
- 布道与施粥同时发生
- 群众行为来自生存和信仰，不是纯礼仪摆拍

# 8. 教堂钟楼与关所（地图裁决已应用）

- 教堂钟楼位于市集广场南端，前有长石阶；圣女在塔前或塔基区域布道
- 关所位于钟楼后方，其底层入口属于牢狱底层；两者制度上邻接，但不是同一建筑或同一上行楼梯
- 教会发布和上层控制可在同一制度空间中呈现，但镜头空间连续性必须服从地图

# 9. 关所内部的唯一上层通道（地图裁决已应用）

- 关所底层入口位于钟楼后方；进入关所内部后才开始上行
- 封闭式运输入口
- 检查岗
- 厚重石门
- 封闭拱口
- 四方回旋楼梯
- 栏杆与集散平台
- 是牢狱通往中层的唯一受控合法主通道；教堂钟楼不承担该交通功能
