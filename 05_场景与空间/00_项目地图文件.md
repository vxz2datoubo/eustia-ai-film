# 《秽翼的尤斯蒂娅》AI电影项目地图文件

> 本文件是所有空间关系、场景拓扑、上下层连接、街区边界、建筑入口、桥梁、通道、角色移动路线与镜头空间连续性的**唯一空间真相源**。场景设定库保存局部材质和使用信息，视觉资产库保存媒体身份，二者都不得自行推翻本地图。

# 1. 空间写入规则

每个空间节点至少记录：

- 正式名称与别名
- 所属层级
- 主要功能
- 相邻节点
- 入口 / 出口
- 高低差
- 方向
- 可见地标
- 角色路线
- 群众流 / 货物流
- 权力与制度功能
- 导演用途
- 状态：locked / provisional / unknown
- 关联资产

同一地点有多个旧名时统一映射，禁止因为别名重复建场景。

## 2.1 方向硬约束

- 主街：**南北向**。
- 高架石桥：**东西向**，横跨主街。
- 绝对关系：**桥在上，主街在下**，不能生成同平面十字路口。
- 北侧链：蔷薇酒馆 / 绯灯街。
- 南侧链：市集 / 布道施粥广场 → 教堂钟楼 → 钟楼后方关所底层入口。
- 当前桥顶视资产约定：画面**下 = 北，上 = 南**。

# 3. 层级结构

## 牢狱 / 平民区底层

包括：

- 莉莉会所
- 绯灯街
- 蔷薇酒馆
- 主街
- 高架石桥与桥下道路
- 市集 / 布道施粥广场
- 教堂钟楼
- 关所底层入口

## 关所内部垂直轴

进入关所以后，空间逻辑从南北水平移动切换为**垂直爬升**：

```text
关所底层入口
→ 内部检查 / 封闭通道
→ 长距离四方回旋楼梯
→ 上升到中层
```

## 中层

- 属于上一海拔 / 上一层级，不是继续向南走就能抵达的同一平面街区。
- 平民区到中层的合法主通道当前只锁定关所这一条。

# 4. 钟楼与关所的最新裁决

这是迁移时必须消除的旧冲突：

- **教堂钟楼不是关所。**
- **钟楼本体不承担通往中层的楼梯交通。**
- 钟楼是市集南端的宗教、公共仪式和视觉地标。
- 关所位于钟楼后方，其入口仍在牢狱底层。
- 进入关所内部后，才通过长距离四方回旋楼梯上升至中层。
- 制作期旧称“通天楼 / 唯一上层通道高楼”只保留兼容检索，不再默认解释成关所后方另一栋独立合法通道建筑。

当前正式文字节点：`SCN-CHECKPOINT-MIDDLE-GATE-001`。

# 5. 绯灯街别名与功能

正式名：**绯灯街**。

原作 / 检索别名：

- 娼妇街
- 娼馆街

人物口语 / 制作旧称：

- 舞女街
- 歌舞街
- 仓库街

裁决：这些名称指向同一片复合街区，不拆成多个独立地点。

功能共存：

- 娼馆、成年性交易、舞女、陪酒、歌舞厅
- 酒馆、药铺、面包铺、杂货与住房
- 仓储、装卸、货物转运
- 不蚀金锁的上纳金、许可和暴力秩序
- 爱丽丝对娼妇和底层居民的医疗
- 贫困、剥削、互助、劳动和日常生活

# 6. 主街与高架石桥

## 主街

- 连接蔷薇酒馆方向与市集 / 钟楼方向。
- 南北向穿过高架桥下。
- 人流、货流和日常行动保持连续，不能因为桥存在而把主街截断。

## 高架石桥

- 东西向横跨主街。
- 桥面承担更高层的横向步行 / 交通。
- 桥下保留主街、货运、推车、仓储补给和低层道路连续性。
- 桥是私人 / 灰色生活区与更公开制度空间之间的重要阈限节点之一。

## 正反打锚点

### 蔷薇酒馆主街锚点

- 北向正打：`SCN-MAINSTREET-ROSE-NORTH-001`
- 南向反打：`SCN-MAINSTREET-ROSE-SOUTH-001`
- 南向远处空间链包含高架桥与钟楼方向。

### 市集北缘 / 钟楼前锚点

- 南向看钟楼：`SCN-CHURCH-BELLTOWER-SOUTH-001`
- 原地转身 180° 向北看桥南立面：`SCN-BRIDGE-SOUTH-FACE-001`
- 对位组：`SCN-MARKET-NORTHEDGE-AB180-001`

# 7. 市集与布道施粥广场

## 定位

牢狱底层最大的公共交易、布道、施粥与群众聚集空间之一。

## 功能

- 日常市集
- 布道与施粥，同一社会事件
- 圣女公开出现 / 觐见
- 教会发布
- 物资分配
- 商贩集散
- 群众消息传播
- 猎羽秩序维护与防疫协管
- 凯姆寻找羽化病男孩的重要场地

## 群众流

- 北侧 / 绯灯街与主街方向的人流进入广场。
- 木碗人群朝施粥区流动。
- 布道、圣女方向形成另一注意力与人流吸引点。
- 商贩推车靠边缘卸货。
- 中央通道需要维持基本疏散与秩序。

## 导演层级

- 高处 / 远中景：圣女、钟楼、制度与宗教权威。
- 中层：群众、菲奥奈小队、凯姆视线搜索等主要人物行动。
- 低处 / 侧边：粥锅、木碗、粮食、摊位等具体生存层。

- 位于市集广场南端。
- 前方有长石阶。
- 是宗教、制度、布道与圣女相关的强视觉地标。
- 正面资产：`SCN-CHURCH-BELLTOWER-SOUTH-001`。
- 面对钟楼时左侧视图：`SCN-CHURCH-BELLTOWER-LEFT-001`。
- 面对钟楼时右侧视图：`SCN-CHURCH-BELLTOWER-RIGHT-001`。
- 后方连接关所底层入口。

# 9. 关所

## 功能

- 平民区到中层的唯一受控合法主通道。
- 人员检查。
- 物资上下运输。
- 上层对牢狱的行政与暴力控制。
- 教会、猎羽、警备力量的制度性邻接空间。

## 空间

- 底层入口在钟楼后方。
- 内部可存在检查岗、厚重石门、封闭拱口、栏杆、集散平台。
- 核心垂直交通为长距离四方回旋楼梯。
- 当前视觉母图缺失，文字拓扑已 locked。
