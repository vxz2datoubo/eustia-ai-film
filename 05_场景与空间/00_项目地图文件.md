# 《秽翼的尤斯蒂娅》AI电影项目地图文件

> 本文件是所有空间关系、场景拓扑、上下层连接、街区边界、建筑入口、桥梁、通道、角色移动路线与镜头空间连续性的**唯一空间真相源**。场景设定库保存局部材质和使用信息，视觉资产库保存媒体身份；场景 / 机位 / 视图 / 媒体 / 关系的机器身份结构由 `10_运行时/scene_asset_identity_schema.yaml` 统一定义。任何其他文件都不得自行推翻本地图。

# 1. 空间写入规则

每个空间节点至少记录：正式名称与别名、所属层级、主要功能、相邻节点、入口 / 出口、高低差、方向、可见地标、角色路线、群众流 / 货物流、权力与制度功能、导演用途、状态和关联资产。

同一地点有多个旧名时统一映射，禁止因为别名重复建场景。

## 1.1 正式世界方向与场景资产身份规则｜2026-08-18当前

- 正式世界方向：**北 = 教堂钟楼 / 关所侧；南 = 绯灯街 / 蔷薇酒馆侧**。
- 主街南北向，高架石桥东西向；桥在上，主街在下。
- 用户层使用中文场景名、中文语义机位名与中文视图名；机器身份使用 ASCII opaque ID。
- 普通视图只用“朝北 / 朝南 / 朝东 / 朝西”；顶视图只用“北朝上 / 南朝上 / 东朝上 / 西朝上”。
- Camera Anchor 中文名优先说明摄影机实际站位，不默认用“机位01/02”；同一语义位置确有多个机位时才加数字后缀消歧。
- 摄影机位置与摄影机朝向是两个独立变量；正反打 / 互看 / 180° / 90°通过显式 Relation 绑定。
- 不建立长期旧ID→新ID解析映射；已迁移旧身份只保留在 Git 历史。
- 世界东南西北独立于 Unreal / OpenUSD / DCC 的 XYZ 坐标轴。

## 2.1 方向硬约束

- 主街：**南北向**。
- 高架石桥：**东西向**，横跨主街。
- 绝对关系：**桥在上，主街在下**，不能生成同平面十字路口。
- 北侧链：市集 / 布道施粥广场 → 教堂钟楼 → 钟楼后方 / 北侧关所底层入口。
- 南侧链：蔷薇酒馆 → 绯灯街；莉莉会所位于绯灯街继续向南一段的**西侧**。
- 从桥下主街过桥向北、朝钟楼方向行进不久，**右手 / 东侧**分出桥北东侧后街窄巷；第一章尤斯蒂娅被追杀、求救、逃跑使用该后街。
- 教堂钟楼位于市集广场**北端**；关所位于钟楼后方 / **北侧**。

## 中层

# 4. 钟楼、通天塔视觉地标与关所裁决

- **教堂钟楼不是关所。**
- **钟楼本体不承担通往中层的楼梯交通。**
- 钟楼是市集北端的宗教、公共仪式和视觉地标。
- 用户2026-08-18确认：从广场南侧中央机位朝北看，钟楼后方可见一座被称为**“通天塔”**的高塔视觉地标。
- 当前只确认“通天塔可见”这一视觉事实；**不得自动把它解释成平民区通往中层的独立合法通道**。合法受控交通职责继续归属钟楼后方 / 北侧的关所及其内部回旋楼梯。
- 关所位于钟楼后方 / 北侧，其入口仍在牢狱底层；进入关所内部后才通过长距离四方回旋楼梯上升至中层。

当前关所文字节点仍为 legacy key `SCN-CHECKPOINT-MIDDLE-GATE-001`，待视觉资产建立后再按新身份 schema 迁移。

# 5. 绯灯街与莉莉会所

## 绯灯街

正式 Scene：`EUS-SCN-000001｜平民区·绯灯街`。

别名：娼妇街、娼馆街；制作旧称舞女街、歌舞街、仓库街。上述名称指向同一复合街区，不拆成多个独立地点。

功能共存：娼馆与成年性交易、舞女 / 陪酒 / 歌舞厅、酒馆 / 药铺 / 面包铺 / 杂货 / 住房、仓储与货物转运、不蚀金锁上纳金与灰色秩序、爱丽丝对底层居民的医疗、贫困 / 剥削 / 互助 / 日常生活。

已锁定语义机位：`EUS-CAM-000001｜蔷薇酒馆门前街段机位`。
- `EUS-VIEW-000001` 朝南：右侧近景见蔷薇酒馆，继续向南是蜿蜒生活区。
- `EUS-VIEW-000002` 朝北：可见高架石桥，远处进入市集 / 钟楼方向。
- 两者为 `EUS-REL-000001 same_anchor_180`。

## 莉莉会所

正式 Scene：`EUS-SCN-000002｜平民区·绯灯街·莉莉会所`。

- 位于绯灯街继续向南一段的**西侧**；人物沿街朝南时在右手边。
- 临街入口由东侧进入建筑，主室内动线向西延伸。
- 固定动线：入口 → 前厅吧台（进门左手）→ 直行穿过帘幕 → 主大厅卡座 / 舞台 → 大厅左侧楼梯 → 二楼回廊办公区。
- 对导演而言，莉莉会所是绯灯街的灰色消费、信息交换、上纳金、人情和雇佣节点，不是孤立装饰空间。

# 6. 主街与高架石桥

正式 Scene：`EUS-SCN-000003｜平民区·主街与高架石桥`。

## 主街

- 连接南侧蔷薇酒馆 / 绯灯街与北侧市集 / 钟楼。
- 南北向穿过高架桥下；桥下道路、人流和货流连续。

## 高架石桥

- 东西向横跨主街。
- 桥面承担较高层横向步行 / 交通，桥下保留主街、推车、仓储补给和低层道路。
- 桥是南侧私人 / 灰色生活区与北侧公开制度空间之间的重要阈限节点。

# 8. 市集与布道施粥广场 / 教堂钟楼

正式 Scene：`EUS-SCN-000005｜平民区·市集广场与钟楼`。

## 定位与功能

位于高架石桥北侧、教堂钟楼南侧，是牢狱底层最大的公共交易、布道、施粥与群众聚集空间之一。承担日常市集、布道施粥、圣女公开出现、教会发布、物资分配、商贩集散、群众消息传播、猎羽秩序维护与凯姆搜索男孩等功能。

## 群众流

- 南侧主街 / 绯灯街方向人流进入广场。
- 木碗人群朝施粥区流动。
- 北侧布道 / 圣女 / 钟楼形成另一注意力与人流吸引点。
- 商贩推车靠边缘卸货；中央通道维持基本疏散与秩序。

## 已锁定正式地面机位

`EUS-CAM-000009｜广场南侧中央机位`：
- `EUS-VIEW-000010` 朝北：市集、钟楼及钟楼后方可见通天塔视觉地标。
- `EUS-VIEW-000011` 朝南：原地反向看到中间高架石桥与桥下向南主街。
- `EUS-VIEW-000012` 朝东：市集 / 钟楼东侧街道、沿街商铺与棚位。
- `EUS-VIEW-000010 ↔ EUS-VIEW-000011` = `EUS-REL-000004 same_anchor_180`。
- 朝北 / 朝东、朝南 / 朝东分别绑定 `EUS-REL-000005 / EUS-REL-000006 same_anchor_90`。
- 朝西旧资产仍待重新上传迁移。
