# 《秽翼的尤斯蒂娅》AI电影项目地图文件

> 本文件是所有空间关系、场景拓扑、上下层连接、街区边界、建筑入口、桥梁、通道、角色移动路线与镜头空间连续性的**唯一空间真相源**。场景设定库保存局部材质和使用信息，视觉资产库保存媒体身份；场景 / 机位 / 视图 / 媒体 / 关系的机器身份结构由 `10_运行时/scene_asset_identity_schema.yaml` 统一定义。任何其他文件都不得自行推翻本地图。

# 1. 空间写入规则

每个空间节点至少记录：

- 正式名称与别名
- 所属层级
- 主要功能
- 相邻节点
- 入口 / 出口
- 高低差
- 方向
- 可见地标
- 角色路线
- 群众流 / 货物流
- 权力与制度功能
- 导演用途
- 状态：locked / provisional / unknown
- 关联资产

同一地点有多个旧名时统一映射，禁止因为别名重复建场景。

## 1.1 正式世界方向与场景资产身份规则｜2026-08-14 用户确认

- 正式世界方向：**北 = 教堂钟楼 / 关所侧；南 = 绯灯街 / 蔷薇酒馆侧**。
- 主街仍为南北向，高架石桥仍为东西向；本次方向裁决不改变已确认的桥上路下、节点邻接、建筑结构和真实可达关系。
- 项目用户层统一使用中文场景名、中文机位名与中文视图名。
- 正式方向只使用绝对东南西北；普通视图用“朝北 / 朝南 / 朝东 / 朝西”，其中方向表示摄影机水平朝向。
- 顶视图用“北朝上 / 南朝上 / 东朝上 / 西朝上”，其中方向表示画面顶部的世界方位。
- **摄影机位置与摄影机朝向是两个不同变量。** 同一场景中允许两个甚至更多机位都朝北，必须通过独立 Camera Anchor 区分。
- “正打 / 反打 / 左视 / 右视”不得作为世界方向，也不得靠名称自动推断；正反打、互看与180°关系由显式 Relation 绑定。
- 机器身份统一服从 `10_运行时/scene_asset_identity_schema.yaml`：Scene / Camera Anchor / View / Media Asset / Relation 使用不携带方向语义的 ASCII opaque ID；中文正式名作为人类可读 metadata。
- 不建立长期“旧ID → 新ID”解析映射。现有旧语义 Asset ID 按正式图片逐张像素核验后执行一次性全引用迁移；事务关闭后旧ID只保留在 Git 历史。
- 世界东南西北独立于 Unreal / OpenUSD / DCC 的 XYZ 坐标轴；未来接入工具时通过显式 transform adapter 转换。

## 2.1 方向硬约束

- 主街：**南北向**。
- 高架石桥：**东西向**，横跨主街。
- 绝对关系：**桥在上，主街在下**，不能生成同平面十字路口。
- 北侧链：市集 / 布道施粥广场 → 教堂钟楼 → 钟楼后方 / 北侧关所底层入口。
- 南侧链：蔷薇酒馆 → 绯灯街 → 莉莉会所。
- 教堂钟楼位于市集广场**北端**；关所位于钟楼后方 / **北侧**。

## 2.2 正式顶视图方向规范

顶视图的主方向不是“摄影机朝向”，而是“画面顶部对应的世界方位”。项目允许四种绝对方位朝上，其中当前优先使用北朝上 / 南朝上：

```yaml
north_up_top_view:
  screen_top: north
  screen_bottom: south
south_up_top_view:
  screen_top: south
  screen_bottom: north
east_up_top_view:
  screen_top: east
  screen_bottom: west
west_up_top_view:
  screen_top: west
  screen_bottom: east
```

- 同一地点可以同时存在不同“朝上方向”的顶视图，它们是不同 View 职责。
- 不以水平镜像或未经用户 / 像素核验的旋转图冒充另一个正式方向资产。
- 当前旧高架石桥顶视资产仍处逐图身份迁移阶段；其最终 View / Media ID 必须在实际打开像素并核对后分配。

# 3. 层级结构

## 牢狱 / 平民区底层

包括：

- 莉莉会所
- 绯灯街
- 蔷薇酒馆
- 主街
- 高架石桥与桥下道路
- 市集 / 布道施粥广场
- 教堂钟楼
- 关所底层入口

## 关所内部垂直轴

进入关所以后，空间逻辑从南北水平移动切换为**垂直爬升**：

```text
关所底层入口
→ 内部检查 / 封闭通道
→ 长距离四方回旋楼梯
→ 上升到中层
```

## 中层

- 属于上一海拔 / 上一层级，不是继续向北走就能抵达的同一平面街区。
- 平民区到中层的合法主通道当前只锁定关所这一条。

# 4. 钟楼与关所的最新裁决

- **教堂钟楼不是关所。**
- **钟楼本体不承担通往中层的楼梯交通。**
- 钟楼是市集北端的宗教、公共仪式和视觉地标。
- 关所位于钟楼后方 / 北侧，其入口仍在牢狱底层。
- 进入关所内部后，才通过长距离四方回旋楼梯上升至中层。
- 制作期旧称“通天楼 / 唯一上层通道高楼”只保留兼容检索，不再默认解释成关所后方另一栋独立合法通道建筑。

当前正式文字节点：`SCN-CHECKPOINT-MIDDLE-GATE-001`（legacy registry key；未来按身份 schema 迁移，不以该字符串推断空间语义）。

# 5. 绯灯街别名与功能

正式名：**绯灯街**。

原作 / 检索别名：

- 娼妇街
- 娼馆街

人物口语 / 制作旧称：

- 舞女街
- 歌舞街
- 仓库街

功能共存：

- 娼馆、成年性交易、舞女、陪酒、歌舞厅
- 酒馆、药铺、面包铺、杂货与住房
- 仓储、装卸、货物转运
- 不蚀金锁的上纳金、许可和暴力秩序
- 爱丽丝对娼妇和底层居民的医疗
- 贫困、剥削、互助、劳动和日常生活

# 6. 主街与高架石桥

## 主街

- 连接南侧蔷薇酒馆 / 绯灯街方向与北侧市集 / 钟楼方向。
- 南北向穿过高架桥下。
- 人流、货流和日常行动保持连续，不能因为桥存在而把主街截断。

## 高架石桥

- 东西向横跨主街。
- 桥面承担更高层的横向步行 / 交通。
- 桥下保留主街、货运、推车、仓储补给和低层道路连续性。
- 桥是私人 / 灰色生活区与更公开制度空间之间的重要阈限节点之一。

# 7. 市集与布道施粥广场

## 定位

牢狱底层最大的公共交易、布道、施粥与群众聚集空间之一，位于高架石桥北侧、教堂钟楼南侧。

## 功能

- 日常市集
- 布道与施粥，同一社会事件
- 圣女公开出现 / 觐见
- 教会发布
- 物资分配
- 商贩集散
- 群众消息传播
- 猎羽秩序维护与防疫协管
- 凯姆寻找羽化病男孩的重要场地

## 群众流

- 南侧 / 绯灯街与主街方向的人流进入广场。
- 木碗人群朝施粥区流动。
- 北侧布道、圣女与钟楼方向形成另一注意力与人流吸引点。
- 商贩推车靠边缘卸货。
- 中央通道需要维持基本疏散与秩序。

## 导演层级

- 高处 / 远中景：圣女、钟楼、制度与宗教权威。
- 中层：群众、菲奥奈小队、凯姆视线搜索等主要人物行动。
- 低处 / 侧边：粥锅、木碗、粮食、摊位等具体生存层。

# 8. 教堂钟楼

- 位于市集广场**北端**。
- 前方 / 南侧有长石阶与广场。
- 是宗教、制度、布道与圣女相关的强视觉地标。
- 当前 legacy 登记含：北向主视图、西向视图、东向视图；最终 Camera Anchor / View / Media ID 必须逐图核验后迁移。
- 后方 / 北侧连接关所底层入口。

- 核心垂直交通为长距离四方回旋楼梯。
