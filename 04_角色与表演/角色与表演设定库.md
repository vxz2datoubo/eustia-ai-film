# 角色与表演设定库

> 所有角色身份、性格、关系、台词与表演原则在本文件原地维护。视觉默认资产只引用 `../06_视觉资产/视觉资产登记库.md` 的 Asset ID，不在这里复制第二套资产状态。资料不足必须写“待导入 / 待确认”，不得自动补全。

# 1. 每次角色导演调用顺序

```text
用户当前明确状态
→ 当前改编剧本命中段
→ 当前连续性
→ 本角色条目
→ GitHub视觉资产登记库中的正式Asset ID
→ AI电影系统相关技能
→ 原作母本 / 专业研究（按需）
```

角色资料不能推翻当前剧本；通用导演规则也不能把每个角色写成同一种“理性正确的人”。

# 4. 凯姆

## 戏剧功能

- 牢狱底层秩序中的执行者、观察者与道德灰区人物。
- 表面冷淡、务实，行动通常比解释更直接。
- 镜头不能轻易把他剪成对制度暴力感到愉快的共犯。

## 表演原则

- 反应克制，视线判断常先于大动作。
- 不用连续皱眉、冷笑、握拳替代心理。
- 面对不想建立连接的人，可持续背对、侧对或拒绝对视。
- 重要转折通过眼神、短暂停顿、重心和距离体现。
- 熟练动作保持真实重量与效率，不自动拍成超级英雄。

## 当前锁定状态

- 第一集当前 30 秒段：已经在攀爬楼房，目标是抢在猎羽之前找到羽化病男孩。
- 全段不需要对白，爱丽丝 VO 与其行动并行。
- 当前默认视觉：`CHAR-KAIM-ID-002`。

## 已锁定桥段

爱丽丝问“想要吗？想要的话就给你”后，凯姆回答“用不着”。爱丽丝随即单手扣住其脖子向上提，凯姆双脚离地。趣味来自爱丽丝冷静愤怒与力量反差，不使用卡通乱蹬和欢快音效。

# 5. 爱丽丝

- 成片统一使用“爱丽丝”，旧资料“艾莉丝”仅作为检索别名。
- 曾接近进入娼馆行业，被凯姆赎出，后在绯灯街为娼妇与底层居民行医。
- 冷淡、毒舌与职业温柔必须同时存在。
- 医者状态比私人状态更稳定、更精准。
- 对凯姆的关心更多通过反话、视线追随、医疗行动和距离控制暴露。
- 愤怒时可减少语言，直接控制距离或身体，不做卡通化暴怒。
- 她对蒂娅的敌意应与被抛弃恐惧、职业责任和隐藏共情并存。
- 当前默认视觉：`CHAR-ALICE-ID-002`。
- 当前 30 秒段：本人不入画，只保留 VO。

# 6. 菲奥奈

## 核心人物原则

- 她真心相信猎羽职责的正当性，不是虚伪体制工具。
- 顽固来自真诚、责任感和信念，不应拍成愚蠢。
- 成长不是放弃正义，而是逐渐区分制度命令与个人选择的正义。
- 少女心只能作为反差，不能削弱队长感和专业感。
- 信念受冲击时，应先出现动作、语言、视线、停顿与构图上的微小裂缝，再进入明确反省。

## 台词指纹

- 直率认真。
- 容易像宣誓、报告或下命令。
- 强调职责、秩序、规则与正义。
- 面对弱者可以放缓语气，但略显笨拙。
- 信念受冲击时出现停顿、自我修正，而不是瞬间反转立场。

## 禁止简化

不得写成：

- 冷血无情的执法机器
- 愚蠢僵硬、毫无反省能力
- 轻浮玩笑型队长
- 只会服从命令的工具人
- 一夜之间否定全部制度的反叛者
- 过度萌化、失去军官感的少女角色

## 当前 30 秒段状态

- 地点：布道施粥广场。
- `preexisting_activity`：带队巡查、人流与排队秩序维护。
- 身边至少 2 名队友，其中 1 人为副队长，至少另 1 人使用与副队长相同制服体系。
- 高处异常只触发轻微职业警觉：眼神先偏上，随后轻微抬头。
- 她不确认看清凯姆，也不启动追捕。
- 队友恰好拦住一名插队男子后，她转回协调现场事务。
- 这一行为证明她为何在场、她的组织职责和职业性格，同时避免抢走凯姆寻找男孩的一级主线。
- 视觉资产：`CHAR-FIONE-ID-001 = pending_review`，未确认前不得当 active。

# 7. 尤斯蒂娅 / 蒂娅

当前已确认核心：

- 第一集冷开场被追杀，承担悬疑、脆弱与世界危险的预载。
- “受惊小动物式胆怯”与内在强韧需要并存。
- 善良不等于无知，温柔不等于无行动能力。
- 勇气可表现为仍然害怕，却主动向前。
- 成长不能通过抹去敏感和温柔完成。
- 完整角色弧光与视觉母图仍待恢复/核验，不得擅自补全缺失资料。

# 8. 奥兹

- 真正动怒前可降低动作密度。
- 强者越克制越可信，不依赖狞笑、低吼、夸张低角度和高密度音乐。
- 威胁通过渐进侵占、负空间坍缩、遮挡、距离和静止权表达。
- 暴力镜头可让结果先于行动者身份出现，但不能制造错误道德归属。
- 动作后必须设计受害者身体后果与场面余震。
- 正式视觉资产目前缺失：`CHAR-OZ-ID-001`。

# 13. CALC / CLCS 与角色库的接口

通用 CALC / CLCS 规则属于 `AI电影系统.md`，本文件只保存每个角色的具体行为指纹与项目事实。

角色出场时必须检查：

```text
镜头前他原本在做什么
→ 当前注意对象
→ 他知道 / 不知道 / 误解什么
→ 什么刺激足以打断
→ 第一冲动
→ 性格 / 职责 / 关系过滤
→ 最终公开行为
→ 中断后恢复还是换目标
```

如果把两个角色名字互换后动作与台词仍完全成立，应判定角色化不足。
