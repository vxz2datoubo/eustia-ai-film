# 视觉资产登记库

> 本文件是角色、场景、服装、白模、深度图、视频参考等**媒体资产身份、状态、职责、默认指针与连续性绑定**的唯一可写文字登记库。媒体本体继续保存在 ChatGPT Library / Project 可访问位置；GitHub 只保存可追溯的 Asset ID、File ID、状态、职责和确认记录。

## 1. 强制入库语义

用户说：

- “登记资产”
- “登记进资产”
- “加入资产库”
- “录入资产”
- “设为正式资产”

默认就是正式 `active` 入库请求。除非用户明确说 `candidate / temporary / pending_review`。

正式完成必须执行：

```text
识别资产身份与职责
→ 检查同类资产 / 默认指针 / 连续性
→ 写本登记库
→ 必要时同步角色 / 场景 / 连续性
→ COMMIT
→ FETCH VERIFY
```

Memory、口头确认或“准备好条目”都不能替代正式入库。

## 2. 状态

- `active`：正式资产；在自己的职责通道中可默认调用。
- `alternate`：合法备选。
- `pending_review`：历史存在但未重新核验，不得默认调用。
- `missing`：登记存在但媒体缺失。
- `active_text_missing_visual`：文字空间节点正式，但独立视觉母图缺失。
- `temporary`：只服务当前镜头，不进入长期身份默认。
- `deprecated`：禁止默认调用。

## 3. 调用优先级

```text
用户本次明确指定
→ 当前镜头连续性绑定
→ 当前职责的正式默认资产
→ 合法备选
→ 明确报告缺失
```
